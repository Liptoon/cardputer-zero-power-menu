# Icon source

`applaunch/share/images/power-menu.png` is derived from the Google Material
Symbols glyph `power_settings_new` (24 px, outlined).

- Source: https://github.com/google/material-design-icons
  (`symbols/web/power_settings_new/materialsymbolsoutlined/power_settings_new_24px.svg`)
- Local copy of the vector: `assets/power-symbol.svg`
- License: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0

The glyph was rasterised at 256 x 256, recoloured white, and placed on a
256 x 256 blue gradient square with ImageMagick.
